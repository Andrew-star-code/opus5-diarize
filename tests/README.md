# Тесты

Три скрипта без внешнего фреймворка — их можно запустить где угодно,
в том числе внутри контейнера, где pytest не установлен. Каждый печатает
построчный отчёт и возвращает ненулевой код при провале.

## Слияние ASR и диаризации

Чистая логика, зависимостей нет — запускается прямо на хосте:

```bash
py -3 tests/test_merge.py
```

Проверяет назначение говорящего по временному перекрытию, разбиение на
реплики по паузам и длине, запасной путь без пословных таймингов.

```bash
py -3 tests/test_smooth.py
```

Проверяет сглаживание артефактов диаризации. Главный случай взят с
реальной записи: фраза «Вы хотите сберечь планету, но противитесь
эволюции» была разрезана на три куска между двумя говорящими. Порога по
длительности для неё мало — вставка длилась 1,1 секунды, — поэтому
работающий признак другой: по обе стороны тот же человек и пауз вокруг
нет, значит речь непрерывна. Две проверки следят за обратным: разные
соседи и пауза вокруг вставки должны её сохранять.

## Сквозной тест backend

Поднимает приложение с временной базой и проходит оба сценария целиком:
живая запись с доводкой, загрузка файла, редактирование текста и
говорящих, статистика, все шесть форматов выгрузки, удаление.

Запускать в контейнере — там уже есть все зависимости:

```bash
docker compose run --rm --no-deps -v "$(pwd)/tests:/tests" -e PYTHONPATH=/srv backend python /tests/test_backend.py
```

58 проверок. Временные файлы и база создаются во временном каталоге и
удаляются в конце, боевые данные не затрагиваются.
