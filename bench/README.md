# Стенд замеров диаризации

Качество диаризации нельзя оценить на глаз по своим записям: у них нет
правильного ответа, с которым можно сравнить. Здесь оно меряется на
записях с эталонной разметкой — трёх встречах корпуса AMI (по 4
участника, английский). Диаризация различает голоса, а не слова, поэтому
на русский цифры переносятся приблизительно, но сравнивать варианты
настройки между собой по ним можно честно.

Главная метрика — **DER**, доля времени, где говорящий определён неверно.
Складывается из пропущенной речи, ложной речи и путаницы говорящих.
Для транскрипта, где у каждого слова один автор, важнее всего путаница:
это ровно те слова, которые пользователь увидит под чужим именем.

## Как запустить

```bash
bash bench/fetch_ami.sh
```

Сервисные воркеры на время замера лучше остановить — стенду нужна
видеопамять:

```bash
docker compose stop worker-live worker-batch
```

```bash
docker compose run --rm --no-deps -v "$(pwd)/bench:/bench" worker-batch python -u /bench/eval_round3.py /bench/data
```

`eval_round3.py` считает по коду самого воркера — проверяет ровно то,
что уходит пользователю. Он берёт распознанные слова из кеша, который
создаёт `eval_round2.py`, поэтому при первом запуске сначала выполните
его (распознавание трёх встреч занимает несколько минут, дальше — из
кеша).

| Скрипт | Что меряет |
|---|---|
| `eval_diarization.py` | Настройки пайплайна: порог кластеризации, склейку пауз, эксклюзивную и обычную разметку, известное число говорящих |
| `eval_round2.py` | Слияние лишних говорящих по сетке порогов, сглаживание по частям, источник меток для слов |
| `eval_round3.py` | Итог: как было и как стало, по production-коду |
